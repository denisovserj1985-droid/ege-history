# Тренажёр ЕГЭ

Сайт: https://denisovserj1985-droid.github.io/ege-history/ (GitHub Pages, ветка main, корень).

Оформление: по умолчанию белый текст на чёрном фоне, крупный шрифт, озвучка. Новое делать так же крупно и контрастно.

## Файлы
- `index.html` — вся программа. В ней же встроены данные «Мегашпоры» по истории (тег `<script id="data">`).
- `mistakes.json` — раздел «Мои ошибки»: ключи `rus`, `hist`, `soc`. Сайт загружает его при каждом открытии.
- `soc.json` — «Шпаргалка по обществознанию»: `secs` = [{id `s_…`, name, q, r, items: [[вопрос, ответ, пояснение?], …]}]. Разделы появляются на сайте сами. Порядок `items` не менять (к индексу привязан прогресс), новые дописывать в конец; новый файл-шпору — новым разделом. Сборщик для задания 13: в репозитории не хранится.
- `maps/NN.jpg` — карты из «Мегашпоры»; NN = номер темы в массиве `maps` (с 00). У тем 00 и 39 карт нет (`MAP_NO` в index.html). Группы похожих карт — `MAP_GRP` (по названию): из них берутся неверные варианты теста и раздел «Похожие карты». Новую карту добавить в подходящую группу.
- `sw.js` — офлайн-кэш. После изменения `index.html` поднять версию `C` (ege-vN). Карты лежат в отдельном кэше `MC`, его поднимать только при замене картинок.

- `manifest.json` — `display: browser`: на iPhone распознавание речи работает только в самом Safari, не в режиме приложения с экрана «Домой».

## Как устроено
- Повторение — FSRS-4.5: формулы и веса по умолчанию прямо в `index.html` (без библиотеки). Прогресс в localStorage `ege_p`: `{s, dd, last, due, lapses, w, reps}`; старый формат `{b, d, w}` переносится автоматически.
- «Выучено» = стабильность от 7 дней. Серия считает любой день с ответом, один пропуск в неделю прощается.
- Тёмные темы без светлых залитых блоков (ГОСТ Р 59587-2021, п. 4.5.2): «верно/неверно» — цветная рамка плюс значок и слово.
- Разделы с `ref:1` (например, «Похожие карты») — только карточки и справочник, в «Всё вперемешку» не входят.

## Как добавлять ошибки
Приходят скриншоты тестов (русский, история, обществознание) с заданиями, где была ошибка. Правильных ответов на скриншотах нет: ответ составляем сами по критериям ФИПИ и проверяем.

Из каждого задания сделать 1–5 коротких карточек и дописать их в конец нужного массива `mistakes.json`:

```json
{"id": "soc-0006", "src": "Умскул · ДД.ММ · задание N", "q": "вопрос", "a": "правильный ответ", "e": "короткое объяснение, почему так"}
```

- `id` уникальный и никогда не меняется (к нему привязан прогресс): rus-0001, hist-0001, soc-0001 по порядку.
- Задание с развёрнутым ответом разбить на несколько простых вопросов.
- Ответ короткий, чтобы его можно было сказать голосом. Пункты писать как «1) …; 2) …».
- Сделать коммит, отправить в main и сообщить, сколько карточек добавлено и по каким предметам.
